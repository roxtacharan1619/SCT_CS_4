# ⌨️ Keyboard Activity Logger

A simple and interactive **Keyboard Activity Logger** built using **HTML, CSS, and JavaScript**. This project demonstrates keyboard event handling by recording keystrokes **only within a designated text area**, making it suitable for learning JavaScript events in a safe and privacy-conscious way.

## 🚀 Features

* Records keystrokes typed inside the text area
* Displays total keystroke count
* Counts special keys (Enter, Backspace, Shift, Ctrl, Alt, Tab, Escape, Delete)
* Shows session timer
* Real-time activity log with timestamps
* Download logs as a `.txt` file
* Clear logs and reset statistics
* Responsive and modern UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

## ▶️ How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. Start typing inside the text area.
4. View real-time keyboard activity, statistics, and logs.
5. Use the **Download Logs** button to save the recorded session.

## 🔒 Privacy & Security

This project is designed for educational purposes and **does not function as a system-wide keylogger**.

* Records keystrokes **only inside the application's text area**.
* No background monitoring.
* No data is sent to any server.
* All logs remain in the user's browser until downloaded or cleared.
